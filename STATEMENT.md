# Statement

Which Erdős problems rest on exact, reproducible evidence, and which only appear to. The audit keeps two questions apart: whether a hosted Lean proof establishes its theorem unconditionally, which is machine evidence anyone can re-run, and whether the formal theorem states the problem Erdős posed, which is judgment and is signed by a named reviewer. A passing verifier answers the first and is silent on the second, and neither answer alone moves a Claim's Standing.

— William Blair, 2026-08-06
