## Repository boundary

- This repository owns Erdős source locks, Target packets, producer artifacts,
  Claims, Submissions, Verifications, Decisions, replay state, and exact next
  obligations.
- [`vela-science/vela`](https://github.com/vela-science/vela) owns the generic
  protocol, CLI, conformance suite, protocol ADRs, and cross-Frontier evidence
  claims.
- [`vela-science/vela-web`](https://github.com/vela-science/vela-web) owns
  removable read projections such as Result Dossiers and their product
  qualification evidence.

No campaign document changes Standing. Only an authorized, attributed Decision
admitted by this Frontier can do that.
