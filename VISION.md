# Erdős Frontier

This repository has one product story:

```text
produce evidence → verify it → decide standing → expose the next obligation
```

Any suitable workbench may produce proofs, computations, or notes. Vela binds
them to exact Claims, Submissions, Verifications, and human Decisions in Git.
The Observatory projects those records for inspection without becoming an
authority surface.

The formalization audit keeps two questions distinct:

- Is the proof unconditional? This is reproducible machine evidence.
- Is the formal statement the intended Erdős problem? This requires accountable
  scientific judgment.

A passing verifier cannot answer the second question, and neither answer changes
Standing until an authorized Decision records it.

The active repository contains only canonical Vela state, exact targets, source
evidence, and scientific artifacts. Generated sites, duplicate graph snapshots,
and historical runtime formats are not active architecture. Historical bytes
remain reachable through Git and the signed predecessor boundary.

The durable rule is:

> Tools produce. Git preserves. Vela verifies and governs Standing. Replaceable
> readers make the result usable.
