# exports

No interoperability export is currently supported by this Frontier.

This directory may contain a generated release artifact only after its
generator records the source commit, tree and repository root; output schema or
profile; exact artifact root; transformation and semantic loss; authority
effect; validation command; and support status. Static JSON is not an MCP
implementation, and a directory name must not imply protocol conformance.

Unpromoted work belongs under `research/export-experiments/` and has
`authority_effect: none`.
