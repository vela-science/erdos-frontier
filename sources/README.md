# Sources

Source manifests, papers, datasets, registries, and protocols.

`archive/vela-internal/manifest.json` is the public, byte-exact mirror of the
15 historical source objects that recovered Erdős attempt records cite from
the private transition repository. The original repository, commit, path,
digest, byte length, and public mirror path are retained for each object.

The mirror preserves provenance and cold readability. It does not change any
Claim, Verification, Decision, Event, or Standing.
