# Erdős 264 package-root replay experiment

This directory is a non-authoritative consumer of the source-local
`vela-science/lean-replay-contract@0.0.0-source-local` candidate. The exact
reference is in `lean-replay-contract.consumer.v1.json`.

The experiment verifies the generic package root and the retained axiom-report
boundary while leaving the accepted Erdős 264 verifier, capsule, Verification
Records, Decisions, and Standing byte-for-byte unchanged. It cannot replace or
rescore those historical objects.

This is not a package release, registry integration, new Verification, or
scientific result. Promotion remains blocked until independent readers and
cross-platform network-disabled reconstruction pass and shared extraction
deletes more maintained logic than it adds.
